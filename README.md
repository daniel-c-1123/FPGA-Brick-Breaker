# FPGA Brick Breaker

## Project Overview
This project recreates brick breaker using an FPGA. The FGPA drives a VGA monitor to display the game and takes inputs from a buttons, switches, and an accelerometer chip to control the game settings and controls. I started this project for the purposes of learning digital design, SystemVerilog, and FPGA. 

## Parts & Technologies used
DE-10- Lite Development Board (MAX-10 FPGA chip)
VGA Monitor
ADXL345 Accelerometer Chip (G-Sensor)

Questa for testbenching
Quartus for synthesizing HDL
